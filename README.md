# Mira Foods

Website for Mira Foods. The first site is for **Bee's Water**, a honey-sweetened drink with vitamin C, for UK consumers.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| Our Flavours | `flavours.html` |
| Ingredients and Wellness | `ingredients.html` |
| Where to Buy (with trade enquiries) | `where-to-buy.html` |
| About | `about.html` |
| Contact | `contact.html` |
| Privacy | `privacy.html` |
| Cookies | `cookies.html` |

Plain HTML, CSS (`css/styles.css`) and a little JavaScript (`js/main.js`). No frameworks and no build step: open `index.html` in a browser, or upload the folder to any static host.

The header and footer are repeated in each page, so a change to the menu or footer needs making in all eight files.

## Before launch

Search the project for `TODO` to find everything that still needs your input: prices, photos, company details, contact details, stockists, and the health claims awaiting approval. Visible TODOs show as yellow dashed tags on the pages.

See [COMPLIANCE.md](COMPLIANCE.md) for the UK rules behind the wording.

## Images

`images/` holds illustrated bottles, a placeholder logo mark and a honeycomb texture. Replace the honey-coloured photo placeholders by putting an `<img>` inside each `<div class="photo">` (the placeholder texture hides itself automatically). Suggested sizes: 1600 px wide, WebP or JPEG, under 300 KB.
